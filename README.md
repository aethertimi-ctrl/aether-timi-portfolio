# Aether Timi — Creative Developer Portfolio

A responsive, dark-luxury personal portfolio and creative-studio landing page.

## Features
- Responsive layout for desktop, tablet and mobile
- Mobile navigation with accessible expanded state
- Animated hero artwork and scroll reveal effects
- Project category filters
- Selected-work links to existing GitHub projects
- Services, about and contact sections
- Reduced-motion preference support
- SEO and social-sharing metadata
- No build step or framework required

## Run locally
Open `index.html` in a browser, or use a local static server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy to Vercel
1. Create a new GitHub repository named `aether-timi-portfolio`.
2. Upload the contents of this folder to the repository root.
3. In Vercel, choose **Add New → Project** and import `aether-timi-portfolio`.
4. Framework preset: **Other**.
5. Build command: leave blank.
6. Output directory: `.` (project root).
7. Deploy.

The project is static HTML/CSS/JavaScript, so no build command or environment variables are required.

## Before launch
- Confirm that `aethertimi@gmail.com` is the preferred public contact email.
- Replace placeholder LinkedIn and Instagram profile URLs with your actual profile URLs once created.
- Review each project link and update any repository or live-demo URL that changes.
- Add your own approved profile photo if desired.
- Check project descriptions against the actual state of each project before publishing.
